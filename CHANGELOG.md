# Changelog

All notable changes to the companion project will be recorded here.

## 2.0.0

- Added reproducible CPU/GPU recognition, constrained local interpretation, selected-event and known-count speaker-grouping studies.
- Added persistent local queue/status/diagnostic commands with exact confirmation, expiry, revocation and duplicate-result recovery.
- Added bounded audio normalization, transcript display layers, literal speech preparation and generated-waveform inspection.
- Hardened frame and scoring limits, local artifact checks, narration output bounds and dictation undo across process restarts.
- Documented the distinct in-memory and persistent permission boundaries and the limits of the measured data.

## 1.0.0 - 2026-10-16

### Added

- Complete searchable archive ingestion, query, and paired deletion workflow.
- Two-phase ASR dictation preview, exact-digest approval, persistent idempotency, and conflict-aware undo.
- Chunked Kokoro narration synthesis, validated PCM16 assembly, and hashed project manifest.
- Typed/audio assistant turns with a closed speech grammar, optional local response speech, and confirmation-gated diagnostics.
- Public-safe CPU application-workflow evidence and adversarial workflow tests.

## 0.1.0 - 2026-10-16

### Added

- Model-independent contracts and four safe reference workflows.
- Deterministic unit tests that require no microphone, model download, network service, or GPU.
- Strict model-artifact manifest validation.
- Reproducibility, security, contribution, removal, and third-party documentation.
- Explicit live input/output device inventory, bounded PCM capture, and bounded playback.
- CPU-only Silero VAD, Faster-Whisper, and Kokoro adapters with injectable test doubles.
- Independent VAD, ASR, TTS, and integrated capture-to-transcript commands.
- Immutable model fetcher, locked artifact manifest, and Windows Python 3.11 dependency lock.
- Local synthetic TTS-to-ASR and VAD integration evidence without model or audio redistribution.
- Public-safe live integration evidence for consented HyperX capture, positive speech detection, exact CPU transcription, and operator-confirmed C34J79x playback.
- MIT licensing and publication-ready repository metadata.

The earlier `v0.1.0` tag retains its original source.
